# MetalFX Direct + 宽屏合并补丁说明

## 目标

让《碧蓝幻想 Relink》在 CrossOver Preview 0821 + DXMT 下使用 DLSS 接口调用 MetalFX Temporal，同时保持 Metal HUD 的绿色 `Direct` 呈现路径。

## 实机结论

1. 原版游戏交换链 `R8G8B8A8_UNORM`、3 buffers、Flip Discard、flags `0x40` 可以走 Direct。
2. ReShade 核心单独加载时仍可走 Direct。
3. Luma 将交换链升级为 `R16G16B16A16_FLOAT` scRGB 后会转为 Composited。
4. 单独移除 `ALLOW_TEARING` 与 `ALLOW_MODE_SWITCH` 仍为 Composited，因此触发点是 scRGB 交换链升级，不是这两个 flags。
5. 保留原始 SDR 交换链后，MetalFX Temporal 可以正常运行并保持 Direct。
6. DXMT 的 `nvapi64.dll` 会触发大量未实现的 `NvAPI_D3D11_MultiDrawIndexedInstancedIndirect`，造成角色和场景缺失；必须为本游戏禁用 NVAPI，同时保留内置 `nvngx`。
7. GBFRelinkFix 在 Wine/CrossOver 下需要 `winmm=native,builtin`；合并工具将它与 `dxgi`、`nvapi64`、`nvngx` 一起写入游戏专用 DLL 覆盖。

## 已知限制

- 不提供 HDR；启用 Luma scRGB HDR 会重新进入 Composited。
- 当前只在 Steam Build ID `24955526`、EXE SHA-256 `4b3ace0f…5145` 上完成实机验证。
- 这是非官方二进制兼容补丁。游戏、Luma、ReShade、CrossOver 或 DXMT 更新后都需要重新验证。
