# 新手安装教程

## 首次安装

1. 退出《碧蓝幻想 Relink》。
2. 双击 `GBFR MetalFX + 宽屏一键工具.command`。
3. 输入 `1`，回车。
4. 在列表中选游戏目录。
5. 选择你真正用来启动游戏的 CrossOver 容器。
6. 等待出现“完整安装完成”。
7. 在 CrossOver 容器设置中打开“高分辨率模式”，启动游戏。

## 正常画面的判定方法

Metal HUD 右上角应同时看到：

- 绿色 `Direct`
- `MetalFX`
- `Scaling Temporal`
- `Scaling Input Res` 小于 `Scaling Target Res`

只看到 DLL 或开关不等于 MetalFX 已实际生效。

## 换了容器

直接再运行工具，仍选 `1) 一键推荐安装 / 修复`，并选新容器。DLL 覆盖和 MetalFX 环境变量都是“按容器保存”的。

## 调整画质

再次运行工具，选 `5) 调整 MetalFX 档位`。

- 50%：性能最好，推荐起点
- 60% / 65%：性能与画质平衡
- 75% / 85%：更清晰，GPU 压力更高
- 100%：几乎没有超分的性能收益

## 画面缺人物或场景

先退出游戏，再选 `8) 运行诊断`。如 DLL 覆盖校验不通过，运行第 1 项修复。关键是游戏专用 `nvapi64=` 必须存在；它用于避开 DXMT 当前未实现的 NvAPI 多重间接绘制路径。

## 宽屏补丁没有加载

运行诊断，确认 `winmm.dll` 和 `GBFRelinkFix.asi` 校验通过，并确认游戏专用 `winmm = native,builtin`。
